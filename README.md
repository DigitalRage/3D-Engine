# Lightweight 3D Engine

WebGL-based lightweight 3D editor/runtime with OBJ as the primary 3D interchange format.

## Current player
The built-in third-person player is a 930-triangle black anime-style silhouette with 18 bones and polygonal white eyes. It uses tapered, angular geometry and blended joint weights for cleaner animation transitions. WASD moves the player; Arrow Keys or mouse/right-drag orbit the third-person camera; Space jumps; Shift sprints.

The player bind-pose asset is also available as `assets/models/player/player_anime_silhouette.obj` with its companion `.mtl`.

## Map assets
The packaged Tokyo map is OBJ/MTL. Large JSON map files are intentionally not shipped.
